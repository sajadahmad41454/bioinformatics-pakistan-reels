# Bioinformatics for Pakistan — Reels

Animated science videos for [@bioinformatics_pakistan](https://www.instagram.com/bioinformatics_pakistan/) and the *Bioinformatics for Pakistan* LinkedIn group.

- `videos/` — finished, watermarked 9:16 Reels (public links are used for scheduled posting)
- `engine/` — the animation engine (matplotlib frames + Kokoro TTS narration + ffmpeg)

All videos are original animations made for science education.
